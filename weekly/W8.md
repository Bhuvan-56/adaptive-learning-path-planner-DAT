## Results

From [`docs/w8/results.md`](../docs/w8/results.md); 1,000 synthetic learners, 5 days, 10-minute budget:

- **Hard constraints:** 0 prerequisite violations, 0 budget violations and 100% trace coverage, in every arm of every run.
- **S0:** identical to Week 7, all 9,000 rows (every column except runtime). adaptive_full − static is +0.1400 [0.1110, 0.1690].
- **S1 before the fix** was identical to S0, confirming the Week 7 correction.
- **S1 after the fix:**
  - every arm loses about 0.45 concepts (adaptive_full 2.1760 → 1.7300, −0.4460 [−0.4940, −0.4000]);
  - adaptive_full − static is +0.1430 [0.1000, 0.1830] concepts and +0.0383 [0.0279, 0.0481] retained recall;
  - best-singleton − greedy is −0.0040 [−0.0190, 0.0130], no difference shown (it was +0.0130 under S0).
- **Best-effort plan:** no effect in the S0/S1 runs (no day was capacity-infeasible), as predicted. It is shown by the tests and the demo preset: a 2-day request gets B and C instead of nothing.

## Deviations (disclosed)

- **Fix 2 implementation:** the day-filling loop was not moved into a helper as pre-registered. The infeasibility check now stores its result and the existing loop runs below it. The behaviour is the same and the full suite passes.
- **"Before" manifest:** the S1 before run read its git SHA after the fixes were committed, so its manifest says `840a12b`. The run was repeated from a checkout pinned at `ace6b00`: identical per-learner files, and a manifest with `ace6b00` saved as `manifest_pinned_ace6b00.json`.

## Decisions

Decision: keep both fixes as default behaviour. The hard constraints hold, S0 is unchanged, S1 now tests forgetting during study, and adaptive_full stays better than both baselines there. The best-singleton fallback stays opt-in: its small S0 gain is not seen under S1.

Decision: report the remediation ablation bug and the identical ablations as limitations rather than fix them in the final week. Fixing the arm cannot change the numbers, because remediation never fires in the loop. The fix is the Track B live change task.
